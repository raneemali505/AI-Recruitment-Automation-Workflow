# AI Recruitment Automation Workflow

## Overview

This project automates the recruitment process using n8n and Artificial Intelligence.

## Features

- Monitor recruitment emails using Gmail Trigger
- Extract resume attachments (PDF)
- Parse resume text
- Classify applications using Qwen AI
- Extract candidate information
- Evaluate candidate suitability against the job description
- Store candidate information in Google Sheets
- Notify HR about qualified candidates
- Send acceptance or rejection emails automatically

## Technologies

- n8n
- Gmail API
- Qwen Cloud Chat Model
- Google Sheets
- JavaScript
